隱私權政策

本系統（阿正自動發文系統）僅供黃守正個人使用，用來把自己的貼文與影片發佈到自己的 Threads、Facebook 粉絲專頁、Instagram 與 YouTube 頻道。

收集哪些資料

只使用平台授權提供的存取權杖，用於發佈自己的內容與在自己的貼文下留言。不收集、不儲存、不分享任何其他使用者的個人資料。

資料存放

權杖以加密方式存放於 GitHub Actions Secrets，不公開、不提供給第三方。

撤銷授權

可隨時於 Facebook、Instagram、Google 帳號的「應用程式與網站」設定中移除授權。

Privacy Policy｜隱私權政策

App: AZheng Video Share · Last updated: 2026-10-29

AZheng Video Share is a private, single-user publishing tool operated by 黃守正 (A-Zheng), a real estate agent in Taichung, Taiwan. It publishes the operator's own videos to the operator's own Threads, Facebook Page, Instagram and YouTube accounts. It is not offered to any other user.

Use of YouTube API Services

This app uses YouTube API Services to upload the operator's own videos to the operator's own YouTube channel (YouTube Data API v3, videos.insert, OAuth scope youtube.upload only). By using this app you agree to be bound by the YouTube Terms of Service. YouTube data is also subject to the Google Privacy Policy.

Information we access, collect and store

  • The only Google/YouTube data stored is the OAuth refresh token for the operator's own channel, kept encrypted in GitHub Actions Secrets.
  • After each upload, the ID and URL of the uploaded video are saved so the operator can see that the upload succeeded.
  • The app does not read, collect, store, display, analyze or share any data about other YouTube users or channels, and it does not use cookies or tracking for YouTube data.

Sharing

No YouTube API data is shared with any third party.

Deleting data and revoking access

Access can be revoked at any time on the Google security settings page. When access is revoked, or on request to the email below, the stored refresh token and saved video IDs are deleted within 7 days. Stored YouTube API data is never kept longer than 30 days without being refreshed.
